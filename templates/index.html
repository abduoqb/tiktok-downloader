▸ Importer une liste de liens

Si TikTok bloque le listing automatique d'un profil, récupérez les liens depuis votre navigateur connecté, puis collez-les ici. Ils sont téléchargés comme d'habitude (historique, pauses, cookies).

  1. Ouvrez le profil sur tiktok.com dans votre navigateur, connecté à votre compte.
  2. Ouvrez la console (touche F12, onglet Console), collez la commande ci-dessous, puis validez avec Entrée. Si le navigateur le demande, tapez d'abord allow pasting. Attendez la fin du défilement : un fichier tiktok_liens_pseudo.txt est téléchargé.
  3. Revenez ici et collez le contenu du fichier (ou choisissez le fichier), puis cliquez sur « Importer et télécharger ».
